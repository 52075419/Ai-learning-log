## 1. 知识点总表

| 课 | 主题 | 必须记住 |
|---|---|---|
| 1 | 变量与对象 | 变量是标签不是盒子；缩进即语法；一切皆对象；函数是第一类公民 |
| 2 | 容器 | `list` 有序可改；`tuple` 不可改，单元素 `(7,)`；`dict` 按键查，不确定用 `get`；`set` 去重，空集合 `set()` |
| 2.5 | 哈希 | 哈希=算固定整数定位；可变对象不能当键（哈希会漂移） |
| 3 | 控制流 + 函数参数 | 空容器/空串/`None` 为假；`for` 是遍历；没有 `++`，用 `+= 1`；默认参数**别用可变对象**，用 `None`；`**kwargs` 是转发神器 |
| 4 | 模块与包 | `import x` / `from x import y` / `as` 别名；第三方库先 `pip install`；密钥走 `os.getenv` 不硬编码；`__name__ == "__main__"` 是入口 |
| 5 | 文件与异常 | `with open` 配 `encoding="utf-8"`；`"w"` 会清空；`json.loads/dumps` 处理字符串，`load/dump` 处理文件；`try/except` 接住错误，API 调用配重试 |
| 6 | 面向对象轻量版 | 类=模板，对象=实例，`self`=当前对象；`__init__` 创建时自动调用；配置存对象，方法调用复用 |
| 7 | 小项目 | 记账本：容器+函数+文件+异常+入口，串起来 |

## 2. 踩坑速查表（15 条）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | `count++` 不存在 | `count += 1` |
| 2 | 缩进混用 Tab/空格 | 统一 4 空格 |
| 3 | 默认参数用 `[]`/`{}` 跨调用共享 | 默认值用 `None`，函数内再创建 |
| 4 | `"w"` 打开即清空 | 追加用 `"a"` |
| 5 | 不写 `encoding="utf-8"` 中文乱码 | `open` 必写编码 |
| 6 | `open` 后忘记 `close` | 一律 `with open(...) as f` |
| 7 | dict 用 `[]` 取不存在的键报 `KeyError` | 用 `get("k", 默认值)` |
| 8 | 空 set 写成 `{}` | 空集合用 `set()` |
| 9 | 单元素 tuple 写成 `(7)` | 写 `(7,)` |
| 10 | `from x import *` 污染命名空间 | 用 `import x` 或导入具体名 |
| 11 | API key 硬编码 | `os.getenv` + `.env` + `.gitignore` |
| 12 | `except Exception` 吞 bug | 能精确捕获就精确捕获 |
| 13 | 类方法忘写 `self` | 实例方法第一个参数 `self` |
| 14 | 方法内 `count += 1` 以为改属性 | 写 `self.count += 1` |
| 15 | `json.dump` / `dumps` 混用 | 带 `s` 是字符串，不带是文件 |
